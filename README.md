# 제4차 슈퍼로봇대전 S — 한글 패치

PlayStation 『第4次スーパーロボット大戦S』(SLPS-00196, Japan Rev 1) 한글화 프로젝트입니다.
패치 파일과, 그걸 만드는 데 쓴 역공학 도구·기술 문서를 담았습니다.

**원본 디스크 이미지는 포함하지 않습니다.** 직접 준비하셔야 합니다.

## 지금 상태 (v0.99)

| 항목 | 값 |
|---|---:|
| 시나리오 대사 (M_BANKS) | 8,990 / 9,070 레코드 (99.1%) |
| 표 슬롯 중 한글을 읽는 것 | 11,002 / 14,336 |
| 스테이지 승리 조건 | 80 / 80 |
| 가라오케 가사 | 124 / 124 |
| 폰트에 새로 그린 한글 | 1,246자 |

화면에 나오는 일본어 대사는 남아 있지 않습니다. 미번역으로 남은 80건은 전부
포인터 표·애니메이션 데이터가 글자로 읽힌 것이라 화면에 뜨지 않습니다.

바꿀 수 없는 것: 타이틀 메뉴와 브리핑 화면의 「승리 조건」·「패배 조건」 **라벨**은
문자열이 아니라 그림입니다. (조건 내용 자체는 한글입니다.)

## 설치

`dist/` 의 xdelta 를 원본 Track 1 에 적용합니다. 자세한 절차와 해시는
[`dist/README.txt`](dist/README.txt) 에 있습니다.

```
xdelta3 -d -s "Dai-4-Ji Super Robot Taisen S (Japan) (Rev 1) (Track 1).bin" \
           Dai-4-Ji_SRW_S_KR_v0.99.xdelta \
           "Track 1 (patched).bin"
```

원본 Track 1 SHA-1 `39241b033cd8368713a30cf5b1a1e5d47fb3d353`
→ 패치 후 `1a8a29146f7560fbdc952b4ad6fb8e5fe180b1ba`

Track 2/3 과 `.cue` 는 건드리지 않습니다.

## 이 게임에서 배운 것

한글화하면서 부딪힌 구조들입니다. 자세한 내용은 `docs/` 에 있습니다.

**같은 데이터가 여러 곳에 있다.** 전투 대사는 디스크에 **세 벌** 있습니다 —
`BTT/M_BANKB.LZB`, STAYDAT 안의 전투 풀, 그리고 `BTT/C_BEFCT.BIN` 꼬리에
**압축된 채** 박혀 있던 세 번째 사본입니다. 전투는 첫 번째를, 맵 대화는 세 번째를
읽습니다. 두 벌만 고쳤을 때는 화면 절반만 한글로 나왔습니다. 폰트도 STAYDAT 과
C_DEMOG 두 벌입니다.

**포인터가 레코드 중간을 가리킨다.** 게임은 같은 대사를 화자 이름만 떼고 재사용하는데,
그 재사용이 문장 중간 바이트를 가리키는 포인터로 되어 있습니다. 번역하면 그 포인터가
읽는 내용이 달라집니다. 원문의 `「`·문단·줄바꿈 경계를 역문의 같은 자리로 이어 붙여
해결했습니다 ([`tools/mb_alias.py`](tools/mb_alias.py)).

**한도는 글자 수가 아니라 바이트, 또는 픽셀이다.** 한글은 2바이트, 일본어 반각 가나는
1바이트입니다. 고정 칸은 바이트로 잘리고, 화면 폭은 바이트 × 8 픽셀입니다.
가라오케 가사 한도가 26바이트인 것도 여기서 나왔습니다.

**공간은 옮겨서 만든다.** 가사가 들어갈 자리가 없어서, D_NAMES 뒤에 있던 상주 blob
`D_DEDMES`(1,166 B)를 잔재 구간으로 옮기고 슬롯을 53,248 → 55,296 B 로 넓혔습니다.
blob 의 RAM 주소가 코드가 아니라 MAP 오버레이의 **주소표**에 들어 있어서 u32 하나만
바꾸면 되는 구조였습니다. 파일 크기는 그대로입니다
([`tools/relocate_dedmes.py`](tools/relocate_dedmes.py)).

**압축기를 다시 썼다.** 게임의 LZB 를 그대로 재압축하면 원본보다 3.5% 커져서 파일이
자리에 안 들어갔습니다. 최적 파싱(DP)과 길이 2 매치를 넣어 원본의 0.98~0.99배로
줄였습니다 ([`tools/lzb_encode.py`](tools/lzb_encode.py)).

**조용한 누락이 기본값이다.** 번역이 빌드에서 빠져도 아무도 알려주지 않습니다.
그래서 모든 단계에 "원본 그대로이거나, 역문과 정확히 일치하거나" 를 강제하는 게이트를
두었습니다. 실제로 이 게이트가 재뱅커 버그 두 개와 원장이 통째로 건너뛴 6줄을 잡아냈습니다.

## 저장소 구조

```
tools/    역공학·빌드 도구 (Python 100개)
docs/     기술 문서 — 포맷 분석, 빌드 절차, 작업 기록
dist/     배포용 xdelta 패치와 설치 안내
```

### 도구 몇 가지

| 파일 | 하는 일 |
|---|---|
| `lzb.py` / `lzb_encode.py` | 게임의 LZSS 계열 압축 해제·재압축 |
| `isotool.py` | Mode2/2352 디스크 이미지 읽기·파일 목록 |
| `patch_image_reloc.py` | 파일 재배치·확장을 반영한 이미지 재작성 |
| `mb_rebank4.py` | M_BANKS 재뱅킹 (표마다 독립 블록) |
| `mb_alias.py` | 레코드 안쪽 별칭을 역문의 같은 구조 자리로 이동 |
| `hangul_font.py` | 16×16 한글 글리프 생성 |
| `reinsert_build.py` | D_NAMES 재삽입 (공유·정렬·폭 검사) |
| `verify_*.py` | 각 단계의 게이트 |

### 빌드 순서

원장을 고친 뒤:

```
mb_rebank4.py --tr → verify_mb_ledger.py / verify_mb_rebank4_tr.py
  → reinsert_build.py → verify_reinsert.py
  → build_staydat_ko.py → build_cdemog_ko.py
  → build_mbankb_ko.py → build_cbefct_ko.py
  → patch_image_reloc.py → patch_image_resize.py
```

번역 원장(`translation/`)은 게임 원문 스크립트를 통째로 담고 있어 저장소에
포함하지 않았습니다. 도구는 원장이 있어야 돌아갑니다.

## 남은 일

- 본편 전수 플레이 검증
- 5화 애인 이름의 **기본값**이 깨져 보이는 문제. 디스크 어느 파일에도 없는 런타임
  조립값이라 아직 출처를 못 찾았습니다. 이름을 직접 입력하면 정상입니다.

## 라이선스와 범위

도구와 문서는 자유롭게 쓰셔도 됩니다.

패치는 원본 디스크에 적용하는 **차분 파일**입니다. 게임 데이터는 들어 있지 않습니다.
『第4次スーパーロボット大戦S』의 저작권은 반프레스토(현 반다이남코)와 각 원작사에
있습니다. 이 프로젝트는 원본을 정당하게 소장한 사람이 한국어로 즐기기 위한 비영리
팬 번역이며, 원본 이미지·추출 데이터·번역 원장은 배포하지 않습니다.

가라오케 모드의 주제가 가사는 각 곡의 저작권자에게 권리가 있어, 가사 파일 자체는
저장소에 포함하지 않았습니다.
