# 제4차 슈퍼로봇대전 S (PS1, 일본판 Rev 1) — 초기 조사

상태: **진행 중 — 가시성 PoC 통과(2026-08-22), 전량 번역 착수 전 남은 게이트 있음**  
기준일: 2026-08-20  
목표 언어: 한국어

## 지원 입력과 보존 경계

- 지원 후보는 `Dai-4-Ji Super Robot Taisen S (Japan) (Rev 1)` 3트랙 BIN/CUE 세트뿐이다. 각 파일의 절대 경로·크기·SHA-256은 `SOURCE_INVENTORY.tsv`를 기준으로 한다.
- Track 1은 `MODE2/2352` 데이터 트랙이다. PVD는 `CD001`, volume ID는 `SRW4S`이며, ISO9660 파일은 60개 엔트리(디렉터리 포함)다.
- Track 2·3은 CD-DA다. 원본 BIN/CUE와 기존 추출본은 수정하지 않는다. 이후 산출물은 원본 디스크 이미지가 아닌 검증된 델타 패치만 배포 대상으로 한다.

## 기존 조사물의 재검증

- 기존 `_work/tools/isotool.py`는 raw MODE2/2352에서 Form 1 사용자 데이터(2048 bytes)를 읽어 ISO9660 디렉터리를 순회한다.
- `records/iso-listing.txt` 기준으로 `extract.py`가 추출한 비미디어 파일 39개를 원본의 LBA·크기와 대조했다. 39/39이 바이트 동일하다.
- 이 추출기는 `.STR` 동영상과 `.DA` 오디오를 의도적으로 건너뛴다. 해당 미디어가 자막 또는 베이크된 일본어를 포함하는지는 **미확인**이며, 한글화 범위에서 제외된 것으로 취급하지 않는다.
- `BTT/BATTLE.LZB`, `BTT/M_BANKB.LZB`, `MAP.LZB`, `MOVIE.LZB`는 제공된 LZB 해제기로 각각 입력 끝까지 소비되어 388,880 / 55,353 / 373,128 / 32,924 bytes로 해제된다. 재압축기와 원본 바이트 왕복은 아직 없다.

## 다음 작업 (2026-08-22 갱신)

가시성 게이트가 통과했으므로 다음 블로커는 **번역문이 길어질 때의 재삽입**과 **번역 모집단 확정**이다.

1. **성장 재삽입 게이트.** 한국어는 원문보다 길어진다. `D_NAMES`(16-bit 절대 포인터)와 `M_BANKS`(은행별 256×16-bit
   고정 표 + `0x400` 읽기 창)에서 문자열이 커질 때의 재배치 정책을 증명한다. 은행 경계를 넘는 54개 레코드,
   포인터를 공유하는 엔트리, 레코드 내부를 겨누는 앵커가 있는지 먼저 확인한다.
   (도너 프로젝트가 같은 계열에서 겪은 실패가 `reference/srwcb-korean-patch/docs/RELEASE_NOTES_v0.11.18/29/34.md`에
   기록돼 있다 — 재조준 누락 옵코드, 레코드 안쪽 앵커, 축약기 부작용.)
2. **모집단 확정.** 이벤트 VM의 분기/점프를 CFG closure로 확장하고 `SC_01–03` 루트 도달성을 풀어 현재
   1,624개 소비자 한정 후보를 실제 라이브 대사 집합으로 닫는다. 여기서 번역 원장이 나온다.
3. **이미지·영상 범위.** `C_*` 컨테이너와 `STR` 영상의 베이크된 일본어를 전수 분류한다. 타이틀 메뉴처럼
   글꼴 경로를 안 타는 화면은 그래픽 교체 대상이다.
4. **최종 글리프 할당표.** 승인된 한국어 코퍼스의 고유 음절 + 보존할 원문 글리프를 세어 `FONT.md`의 절차대로
   1,536개 16×16 슬롯에 배치한다.
5. **재인코딩 문자열의 실기 확인.** PoC에서 패치한 지형·시나리오 제목·파일럿명이 화면에 나오는 지점까지
   진행해 확인한다(1화 세이브스테이트 재사용).

현재 입력·기존 추출·CD 파일 인덱스·STAYDAT 하위 파일·`D_NAMES` 원문 inventory·주 글꼴 저장/소비 계약·
LZB 왕복·크기 보존 이미지 왕복·가시성 PoC를 통과했다. 전체 CFG/동적 루트, 성장 재삽입, 이미지 범위,
최종 할당표, 배포 빌드는 미완료다. 세부 구조는 `ARCHITECTURE.md`, 텍스트 범위는 `TEXT_MAP.tsv`,
글꼴은 `FONT.md`, PoC 결과는 `POC.md`를 기준으로 한다.
