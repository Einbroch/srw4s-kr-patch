# 대사 어조 방침 (M_BANKS)

도너 승인 용어집은 **표기**만 정하고 어조는 정하지 않는다. 그래서 여기서 정한다.
사용자 지시 없이 내가 정한 것이므로, 뒤집고 싶으면 이 문서를 고치고 일괄 재검토한다.

## 기본
- **반말이 기본**이다. 슈퍼로봇대전 대사 대부분이 동료 간 대화다.
- 상하관계가 뚜렷할 때만 존대: 부하→상관, 민간인→군인, 부하 병사→적 간부.
- **과도한 역할어를 쓰지 않는다.** 일본어의 `わし`(노인)·`だぜ`(남성)·`〜わ`(여성)를
  한국어 노인말투·`~라구`·`~예요` 남발로 옮기면 번역투가 된다. 인물의 태도로 살린다.

## 계열별
| 계열 | 어조 |
|---|---|
| 열혈 주역 (료마·코우지·벤케이·효마·카즈야·반죠) | 반말, 짧고 강하게. 외침은 그대로 외침 |
| 지휘관 (브라이트·코우) | 부하에겐 반말 명령조, 상관·손님에겐 존대 |
| 냉정형 (크와트로·아무로·슈우) | 반말이되 절제된 문어체. 감탄 적게 |
| 여성 인물 (사야카·마리아·치즈루·화) | 자연스러운 현대 한국어. 여성어 어미 강제하지 않음 |
| 적 간부 | 위압적 반말. 부하에겐 명령조 |
| 마스코트·요정 (챰·벨) | 짧고 발랄한 반말 |

## 형식 규약
- **표식은 원문과 같은 개수·같은 종류로 유지**한다. `{N}` 줄바꿈, `{B:xxxx}` selector,
  `{8:xx}` 수치 삽입점 등. 하나라도 빠지면 게임이 멈춘다(D_NAMES에서 실증).
- 화자 표기 `이름「...」`는 원문 구조를 유지한다. 이름은 도너 승인 표기를 따른다.
- `{N}`은 원문의 줄바꿈 위치다. 한국어 길이가 달라지므로 **의미 단위로 옮겨 붙여도 된다**
  — 다만 개수는 유지한다.
- 말줄임 `...`은 원문 그대로. 느낌표 개수도 원문을 따른다(외침의 세기 정보다).
