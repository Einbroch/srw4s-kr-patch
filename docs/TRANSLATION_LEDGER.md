# D_NAMES 번역 원장

기준일: 2026-08-23  
위치: `translation/dnames_ledger.json` (schema `srw4s-dnames-ledger-v1`)

## 1. 모델 — span 교체

레코드 전체를 역문으로 갈아끼우지 않는다. 레코드 안의 **번역 대상 구간(span)만** 바꾸고
나머지 바이트는 그대로 둔다. 도너(`second_ui_scripts_overlay.json`)가 쓰는 모델과 같다
(`structural_decoration_glyphs_preserved`, `kana_name_entry_grids_preserved`).

D_NAMES 레코드 44,620 B 중 번역 대상은 **21,595 B(48.4%)** 뿐이다. 나머지는 창 그리기 타일,
제어 토큰, 이름 입력 팔레트, 아이콘 조각이다.

| 필드 | 소유 |
|---|---|
| `source.*`, `id`, `pointer`, `owners`, `raw_hex`, `raw_len`, `spans[].start/end/jp` | 추출기 — **보호** |
| `spans[].ko`, `spans[].status`, `spans[].note` | 번역 단계 — 수정 가능 |

재실행(`tools/build_dnames_ledger.py`)은 역문·상태·근거를 보존하고 보호 필드만 다시 채운다.
보호 필드가 달라진 레코드는 `stale`로 표시해 차단한다.

## 2. span 분류기

`tools/span_classify.py`. 위치 토큰(`FC`/`FD`) 뒤의 글리프 런만 후보로 보고 다음을 제외한다.

- **창 그리기 DSL**: `-…ー` `F…G` `B…C` `〜…?` + 대문자 라틴 다수
- **이름 입력 팔레트 행**: 글리프 **ID의 연속성**으로 판정한다(인접 ID 차 1–4가 70% 이상).
  디코딩된 텍스트의 문자 중복률로 판정하면 `行動終了していないユニットが` 같은 정상 문장까지
  걸러진다 — 실제로 걸렀다가 이 기준으로 고쳤다.
- **아이콘·커서 조각**: 스크립트 레코드 안의 6자 이하 + 라틴·일본어 혼합 런(`工C`, `F州`, `枚ヂGゅ`)

위치 토큰이 없는 레코드(이름·용어)는 전체가 텍스트다.

### 고친 함정

`dnames_sections`의 `raw`는 **항상** 종단 FF를 뺀 형태인데, 레코드의 마지막 바이트가 확장
글리프의 trail로 `0xFF`일 수 있다. `raw.endswith(FF)`로 "이미 종단이 있다"를 판정하면
7개 레코드가 파싱 실패했다. `bytes.find(FF)` 함정과 같은 종류다. 항상 붙이는 것으로 고쳤다.

## 3. 검증 게이트

`tools/verify_dnames_ledger.py` — 현재 통과.

1. 출처 sha256이 현재 추출과 같은가(stale 차단)
2. 모든 `raw_hex`가 현재 추출에서 다시 만든 값과 같은가
3. span이 레코드 안이고, 겹치지 않고, 순서대로이고, 그 구간에서 디코딩한 원문이 `jp`와 같은가
4. **글리프 커버리지**: 역문의 모든 문자가 표현 가능한가(low bank 또는 KS X 1001 한글).
   불가능하면 빌드 에러다.
5. 상태값이 정의된 집합 안인가
6. 재인코딩 시뮬레이션: span을 역문으로 바꾼 레코드가 토큰 계약을 지키고 종단이 정확히 하나인가

## 4. 반각 공백 확정

역문에서 유일하게 표현 불가였던 문자가 **공백**이었다. low bank 비트맵을 훑으니
**글리프 `0x000`이 전부 0인 빈 8×16**이다 — 도달 가능한 유일한 반각 공백이라 공백을
**1바이트**로 인코딩한다. `0x0F0`–`0x0FF`도 비어 있지만 `F0`–`FF`는 lead/제어라 글리프 코드로
만들 수 없다(`FONT.md`). 전각 공백은 `0x3FF`(2바이트)다.

이 하나로 성장률이 1.416배 → **1.332배**로 떨어졌다.

## 5. 배치 도구

`tools/batch.py export|merge`. 배치 TSV에 보호 스냅샷(record id, span 좌표, 원문)을 함께 실어
보내고, 병합할 때 현재 원장과 대조해 다르면 **stale로 차단**한다. 역문 칸이 비면 건너뛴다.

### 승인표를 따르지 않은 2건 (근거 기록)
- `射程` → **사거리** (승인표 `사정` 미채택). 승인표 판단 원칙 4번이 한자음 직역을 배제하는데 `사정`이 여기 어긋나고, 폭에도 여유가 있다.
- `リョウ` → **료마** 유지. 승인값 `료`는 대사 화자 태그용이고 이 span은 로스터다(도너 notes에 구분이 명시돼 있다).
